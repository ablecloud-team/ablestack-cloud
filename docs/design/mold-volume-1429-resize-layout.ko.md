# 볼륨 크기 변경 대화상자: 입력 중심 배치

사용자가 승인한 첫 번째 목업을 적용한다. 상단의 할당 정책·적용 증거 요약과 오퍼링 이름 블록을 제거하고, 볼륨 이름·유형으로 대상을 식별한 뒤 바로 크기를 입력한다. 할당 정책과 증거는 기존 세로형 상세 탭에서 확인한다.

- 크기 입력의 레이블 옆에 현재 GiB를 표시하고 단위를 입력 오른쪽에 붙인다. 크기 제한·컴퓨트 ROOT 안내·증감량은 해당 입력 아래에 표시한다.
- 최소·최대 IOPS를 데스크톱에서 나란히 배치하고 좁은 화면에서는 세로로 전환한다. 각 레이블 옆에 현재값을 표시한다. 빈 값 유지와 명시적 0 안내, 고정 IOPS 읽기 전용 표시는 보존한다.
- 자동 마이그레이션은 유효한 크기 변경이 있을 때만 접힌 추가 옵션으로 노출한다. IOPS만 변경하거나 크기를 유지하는 요청에는 해당 파라미터를 보내지 않는다.
- 축소를 입력하면 기존 형식·상태·하이퍼바이저 제한에 따라 지원 불가 사유 또는 기존 축소 동의를 크기 입력 가까이에 표시한다. 동의 컨트롤은 크기 FormItem의 수집에서 분리한다. 이 UI 수정으로 RBD 축소 지원을 추가하거나 보장하지 않는다.
- 하단에는 실제 전송 계약으로 산출한 크기 증감·IOPS 변경 요약과 취소·변경 버튼을 둔다. 요약이 계산되지 않는 입력은 검토가 필요함을 표시한다.

기존 대상 오퍼링 단건 조회, 현재값 초기화, 부분 payload, 제출 전 재조회·충돌 감지, 권한·대상/사용자/프로젝트 전환 가드, 중복 제출 방지, 입력·서버 오류 보존 및 동일 작업 ID 재확인은 유지한다. 계약 유틸리티와 서버 API는 변경하지 않는다. 계산된 화면 요약은 네트워크 요청을 수행하지 않는다.

검증은 기존 계약 회귀 테스트와 UI 모듈 린트·production build, 31 GFS2·32 RBD 배포 후 실제 대화상자와 API/DB/이미지 대조로 진행한다. 테스트 자원은 전용으로 생성하고 검증 후 정리한다. 전체 Cloud 빌드와 Maven/JAR/Agent/qemu 변경은 이 수정 범위에 없다.
