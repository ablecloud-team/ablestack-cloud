# VOL-10 잔여 API/UI 매핑과 권한 계약

대상: Epic #1422 / #1432. 기존 #1154 전용 디스크 링크, #1209 오퍼링 개수, #1210 VM 표시이름, #1433 전체 VM UI 표준, #1434 통합 종료 판정은 각 이슈가 소유한다. #1437은 해결 상태를 유지한다.

## 변경과 실패 처리

수정은 실제 변경 필드만 전송한다. 컴퓨트의 이름 수정/상태/접근 범위 변경이 `purgeresources`를 기본 false로 바꾸던 서버 경로를 고친다. 원래 DB 값과 명시적 파라미터 존재를 구분한다. 외부 상세 복제는 External:만 골라 접두어를 제거한 뒤 API 계약대로 전송한다.

외부 상세의 교체·정리 쿼리는 현재 오퍼링 ID와 External: 접두어 조건을 모두 사용한다. 다른 도메인 및 공용 오퍼링의 테스트 값을 함께 두고 대상만 변경되는지 API/DB 회귀를 확인한다.

컴퓨트 편집과 디스크/컴퓨트 접근 범위는 기존 세로형 상세와 입력 중심 대화상자를 유지한다. API 메타데이터에 있는 필드만 노출하고 Domain Admin의 태그 설정 권한도 조회한다. 접근 범위의 네트워크/VPC 오퍼링은 이번 변경 대상이 아니다.

새 대화상자는 초기 조회/목록 실패 시 저장을 막고 사유·재시도를 제공한다. 저장 직전에 대상의 소유권·상태·설정을 다시 읽어 충돌을 거절한다. 읽기/쓰기 실패에서 세션·입력을 보존하며 전송 결과 미확인은 중복 요청을 막고 서버 재조회를 요구한다. 리소스·로그인·프로젝트 전환과 오래된 응답은 분리한다. 실제 401은 공통 인증 처리를 유지한다.

소유권 이전은 대상 계정 또는 프로젝트 UUID 하나만 전송한다. 현재 프로젝트 자동 파라미터를 제거해 출발 프로젝트를 목적지로 혼동하지 않으며, 선택·서버 대상 목록과 상태를 다시 확인한다. 서버에서 최종 ACL·스냅샷·연결·한도를 검사한다. 이전 후에는 목록으로 이동하고 원본 소유자의 접근이 바뀔 수 있음을 안내한다. 디스크 복사·정책 변환으로 설명하지 않는다.

## 검증

31 GFS2/32 RBD의 전용 A/B 도메인, Domain Admin, 소유자/동일 도메인 다른 사용자/다른 도메인 사용자와 프로젝트를 사용한다. UI와 직접 API에서 허용·빈 조회·거절을 구분한다. 이름/정리 정책/외부 값/접근 범위/복제/활성 상태, 연결·분리와 소유권 이전, UUID 직접 입력, 이벤트/코멘트·관련 조회, 실패/재시도/중복 요청과 원본 데이터 보존을 대조한다. RAW의 checkVolume 거절은 지원 성공으로 집계하지 않는다. 필요한 수정 Maven 모듈과 UI만 WSL ext4에서 빌드하며 전체 Cloud CI는 실행하지 않는다.

운영 자원과 FT 작업을 보존하고 테스트 VM·볼륨·이미지·계정·프로젝트·네트워크를 정리한다. 오퍼링은 API의 Inactive 계약과 제품 이력을 유지한다. 각 API의 UI 위치/의도적 미노출·권한·상태·스토리지·후속 이슈는 검증 보고서의 전체 매핑에 고정한다.
