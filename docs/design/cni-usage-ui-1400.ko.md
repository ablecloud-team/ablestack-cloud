# CNI 사용 Kubernetes·노드 UI (#1400)

## 화면과 조회 계약

CNI 상세의 `/vm?userdata=<UUID>` 바로가기를 제거하고 `사용 Kubernetes` 탭을 추가한다. 기존 일반 UserData의 `userdataid` VM 바로가기와 사용처 탭은 유지한다.

클러스터 목록은 이름·UUID·상태·계정 또는 프로젝트·도메인·연결 노드 수를 표시한다. 행을 펼치면 해당 클러스터 응답의 실제 virtualmachines 관계만 표시하며 노드 이름·UUID·상태·역할과 VM 상세 링크를 제공한다. 전체 VM 목록을 조회하거나 이름/복제 본문으로 노드 관계를 추정하지 않는다. 프로젝트 링크는 대상 projectid를 전달한다. 노드 조회 권한이 없으면 노드 행과 링크를 표시하지 않는다.

`listCniConfiguration`으로 활성 CNI의 UUID·이름·소유 범위를 확인한 뒤 `listKubernetesClusters(cniconfigurationid, owner, page, pagesize, keyword)`를 호출하고 CNI 식별 정보를 다시 확인한다. CNI·클러스터·노드의 UUID/중복/소유 범위 및 총계를 검증한다. 프로젝트 CNI는 명시적인 projectid를 사용하고 계정 CNI는 account/domainid/ignoreproject를 사용한다. 현재 프로젝트가 다른 소유 범위이면 이전 결과를 지우고 목록 재선택을 안내한다.

권한 메타데이터와 cniconfigurationid 지원이 확인되지 않으면 요청을 보내지 않는다. 필터를 제거한 전체 목록 요청으로 대체하지 않는다. CNI·클러스터 조회 권한이 없으면 탭을 숨기거나 접근 거부를 표시한다. 조회 오류/미지원/권한/대상 없음/소유 정보 변경은 정상 0건과 구분한다. 서버의 ACL과 #1399 삭제 보호가 최종 권한·참조 판정이다.

## 비동기 상태와 이동

검색·페이지·페이지 크기는 CNI 탭 전용 URL 키(cnikeyword/cnipage/cnipagesize)로 보존한다. 원래 상세의 소유 범위·검색 URL 값과 다른 탭의 상태를 덮어쓰지 않는다. 페이지 크기 변경은 1페이지부터 시작하고 참조가 줄어든 경우 마지막 실제 페이지로 보정한다. 탭 전환은 Vue router를 통해 이력과 뒤로/앞으로 이동을 지원한다.

동일한 요청 범위의 새로고침은 기존 표(정상 빈 표 포함)와 펼친 노드를 유지한다. 일시 오류는 이전 결과임을 표시하며 재시도할 수 있다. 최초 조회·검색/페이지·CNI/소유 범위·로그인/권한 변경은 이전 결과를 지운다. 요청 세대와 소유 범위, 탭 활성 여부를 확인하여 늦은 응답·떠난 화면의 응답을 게시하지 않는다. 권한 거부·대상 소실·식별 불일치는 이전 표·노드를 즉시 지운다.

## 구성과 검증

- `CniUsage.vue`: VM 상세 탭과 같은 공용 toolbar/pagination, 중간 크기 표, 상태 컴포넌트와 좁은 화면의 수평 스크롤을 사용한다.
- `cniUsage.js`: CNI/사용처 API 계약, 소유 범위와 응답 검증을 담당한다.
- `compute.js`: 잘못된 CNI 관련 VM 링크만 제거하고 사용처 탭을 등록한다.
- `ResourceView.vue`: CNI 상세에서도 router 기반 탭 이동과 숨겨진 탭의 안전한 기본 탭 복귀를 적용한다.
- 한글/영문 메시지를 추가한다.

집중 테스트로 정확한 CNI/소유자 필터, 무필터 요청 방지, 실제 노드 관계, 권한/오류/재시도/빈 목록, 지연 응답·범위 변경, URL/페이지 보정, 링크/일반 UserData 회귀를 확인한다. lint와 production UI build 후 정적 파일만 배포하고 기존 JAR/PID/WEB-INF/META-INF/config.json을 보존한다. Maven 소스 변경과 전체 Cloud 빌드는 없다.

31번의 새 전용 CNI·프로젝트 클러스터에서 실제 API의 클러스터 수·노드 UUID와 화면을 대조하고 링크, 검색/페이지/새로고침, 실패/재시도, 소유 범위 전환을 검증한다. 검증 후 전용 자원과 호스트 도메인을 정리하고 기존 CNI/Kubernetes·운영 DB 기준선을 대조한다.

삭제 확인/완료 UX는 #1403, CNI 메뉴 전체의 VM 표준 스타일 정합성은 #1408에서 계속 다룬다. 이번 새 탭은 공용 VM 탭의 표/간격/로딩 기준을 따른다.
