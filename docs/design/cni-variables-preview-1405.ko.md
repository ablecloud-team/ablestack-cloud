## 현재 경로와 변경

현재 서버는 AS_NUMBER만 직접 치환하며 일반 변수는 노드 메타데이터로 보낸다. Map.toString 저장과 쉼표 분리는 쉼표/등호/개행이 포함된 값의 경계를 보존하지 못한다. 일반 변수도 선언된 단순 {{ NAME }} 토큰에 한해 서버가 리터럴 치환하도록 확장하고 같은 렌더러를 읽기 전용 previewCniConfiguration과 실제 control 노드 구성 생성에서 사용한다. 정규식 치환 값이나 템플릿 재평가는 사용하지 않는다.

비 Jinja 본문의 이름은 등록과 같은 영문자/밑줄 시작, 영문자/숫자/밑줄/점/하이픈 규칙이다. 공백/탭이 있는 단순 토큰·반복·인접 토큰을 지원하고 역슬래시가 앞선 토큰은 이스케이프한 리터럴이다. 선언하지 않은 토큰은 보존하고 미해결 목록에 표시한다. 선언된 변수의 값 누락/여분 값은 미리보기에서 표시하고 생성 시 부작용 전에 거부한다. 빈 문자열은 명시적으로 입력한 값으로 인정한다. AS_NUMBER는 소유 네트워크의 서버 할당값을 우선하며 사용자 정의 값으로 전달하지 않는다. 아직 할당 전인 자동값은 미해결 상태로 표시한다.

Jinja 헤더의 일반 표현식은 서버에서 실행하지 않는다. ds.meta_data.NAME 단순 참조는 변수 후보와 전달할 메타데이터를 표시하고 원문을 보존한다. 기존 AS_NUMBER 서버 치환은 유지한다. UI나 서버가 임의 템플릿/셸을 실행하거나 환경 정보를 가져오지 않는다.

새 CNI 변수 값은 길이 제한을 검사한 JSON으로 저장/전달하며 NetworkModel과 가상 라우터 CommandSetupHelper의 메타데이터 전송은 JSON과 기존 문자열 맵을 모두 읽으며 빈 맵도 안전하게 처리한다. 기존 행은 변경하지 않는다. 일반 UserData의 기존 저장 계약은 유지한다.

## UI와 접근 제어

등록 화면은 명시적인 변수 추출 버튼 → MoldDialog 후보 확인 → 선택 적용으로 선언 목록만 합친다. 이름·본문·기존 변수는 적용 전 유지한다. 잘못된/예약 키와 지원하지 않는 표현식은 후보로 자동 등록하지 않는다.

Kubernetes 선택 영역에 치환 미리보기 버튼을 두고 서버 응답의 실제 전송 본문·변수 값·누락/여분/미해결 상태를 별도 MoldDialog로 표시한다. CNI/소유자/네트워크/AS번호/값 변경 시 이전 응답을 비우고 늦은 응답을 무시한다. 최종 생성은 서버에서도 재검증한다. 원문과 비밀 값은 요청/응답 민감 정보로 표시하고 미리보기를 저장하지 않는다.

CNI UUID 접근은 기존 계정/도메인/프로젝트 ACL 및 for_cks 유형을 검사한다. 네트워크 자동값 조회도 네트워크 접근 권한을 검사한다. draft는 인증된 호출자가 전송한 본문만 처리한다.

MoldDialog/detail-tab-toolbar/작은 표/코드 내부 스크롤과 공통 테마를 사용한다. 상시 설명·API 구현 문구를 본 화면에 추가하지 않는다. 각 기능의 전용 도움말과 필요한 오류/상태만 제공한다.

## 검증과 배포

리터럴/이스케이프/인접·반복/정규식 특수문자·쉼표·등호·한글·개행/AS_NUMBER/Jinja 보존·누락·여분·ACL을 집중 테스트한다. 변경 Maven 모듈만 WSL ext4에서 빌드한다. 31번에서 UI 선언·미리보기·요청·DB JSON·게스트 파일 바이트 및 기본 Kubernetes 부트스트랩/노드 Ready를 대조한다. CNI 전환/해제와 등록·추출·미리보기의 4개 폭×양 테마/오류·키보드를 확인한다.

테스트 전용 CNI/클러스터/네트워크·소유 범위를 정상 API/UI로 정리하고 기존 CNI 3개·Kubernetes 7개·선택 DB 36행과 비교한다. JAR은 변경 클래스만 교체하고 나머지 엔트리를 검증하며 정적 UI는 WEB-INF/META-INF/config를 보존해 배포한다. 전체 Cloud 빌드는 실행하지 않는다. #1406 복제 → #1407 이력/비교는 후속 범위다.

CNI 값 입력은 자동 높이 조절 textarea로 제공해 실제 개행을 입력할 수 있다. JSON은 비 ASCII 문자를 Unicode escape로 저장해 기존 DB 문자셋에서도 보존하며, 치환 결과도 서버의 현재 본문 길이 제한으로 검증한다.

AS 번호 조회도 미리보기와 실제 control VM 생성이 같은 함수를 사용한다. 새 네트워크에서 생성 중 자동 할당된 값도 control VM 구성 생성 시 조회하며 제안 값보다 할당된 네트워크/VPC 값을 우선한다. 아직 네트워크가 없는 미리보기는 대기 상태를 그대로 표시한다.
