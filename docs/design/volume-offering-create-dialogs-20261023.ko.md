# 컴퓨트·디스크 오퍼링 추가 대화상자 정리

Epic #1422 / 누적 Draft PR #1435의 승인된 오퍼링 생성 목업을 구현한다. 새 추가 대화상자가 대상이며 기존 시스템 오퍼링·복제 폼의 정책 값과 수명주기 검증은 유지한다.

## 입력 구조

두 폼에 **기본 설정 / 볼륨 배포 / 고급 옵션** 탭을 사용한다. 기본 설정에는 이름·설명과 컴퓨트 사양 또는 디스크 크기를 둔다. 볼륨 배포에는 루트 디스크의 직접 지정/오퍼링 연결, 이미지 형식·배포 정책, 별도의 스토리지 배치 조건을 둔다. 고급 옵션은 컴퓨트 동작, GPU·플래너, 캐시·QoS, 공개·사용 범위, 수명주기·외부 연동을 접어서 표시한다.

추가 폼의 하이퍼바이저 QoS는 읽기/쓰기 처리량과 IOPS의 기본 한도 4개를 먼저 표시하고 버스트 한도·지속 시간은 별도의 접을 수 있는 영역으로 둔다. 접어도 필드를 마운트한 상태로 보존하고, 잘못된 버스트 값은 영역을 펼쳐 수정하도록 한다. 기존 편집·복제의 전체 QoS 표시는 유지한다.

탭 내용은 모두 마운트한 상태로 유지한다. 단순 탭 이동 때문에 Vue form ref가 사라지거나 필드가 제출에서 빠지지 않아야 한다. 기능 선택에 따른 기존 조건부 마운트는 유지한다. 오류가 있는 탭을 활성화하고 고급 그룹을 펼쳐 수정할 수 있도록 한다. 입력·제출 실패 시 폼과 세션을 보존하고 중복 제출을 막는다.

## 볼륨 설정 방식

- `할당 정책 계약`은 `볼륨 설정 방식`으로 표시한다.
- `Europa 방식 (기본)`을 먼저 표시하고, 지원 API의 새 오퍼링에는 RAW / Thin(off)를 초기값으로 사용한다. 관리자가 형식·정책을 변경할 수 있다.
- `기존 방식 (Diplo 호환)`은 thin/sparse/fat를 그대로 전달한다. API 스키마에 새 정책 매개변수가 없는 경우 기존 방식을 사용한다. 기존 오퍼링을 자동 전환하지 않는다.
- 참조 스토리지 선택, 그에 따른 풀·호스트·Agent capability 조회 및 오퍼링 저장 전 조회 의존성을 제거한다. 오퍼링은 특정 풀에 결합되지 않은 관리자 정의이다.
- UI는 구현된 형식·정책의 정의 조합만 검사한다. 실제 풀·호스트·작업 지원, 용량, 실행 결과 검증은 기존 볼륨 배포 경로가 담당하며 이를 제거하거나 성공으로 가장하지 않는다.

| 실제 배포 경로 | 정책 정의 |
| --- | --- |
| GFS2 RAW | off / falloc / full |
| GFS2 QCOW2 | metadata / falloc / full |
| RBD RAW | off / full |

RAW metadata와 QCOW2 off는 현재 검증된 배포 조합에서 제외한다. RAW falloc은 GFS2 전용임을 표시한다. RBD에 QCOW2·falloc·지속 예약 지원을 추가하지 않는다. RBD Full은 현재 검증된 생성·전체 복사 경로의 범위이다. Europa 방식의 로컬 스토리지 및 암호화 배포는 지원 대상으로 표시하지 않는다.

스토리지 태그는 형식/정책 검증용 풀이 아니라 모든 태그가 일치해야 하는 배치 조건으로 별도 표시한다. 컴퓨트가 일반 디스크 오퍼링을 연결한 경우에는 해당 오퍼링의 형식·정책·태그를 읽기 전용으로 보여주고 직접 입력과 캐시·QoS의 중복 제출을 하지 않는다.

## 검증과 배포 기준

정책 조합·구 API·기존 값 보존, 탭 이동과 오류 탭 전환, 실제 제출 필드와 중복 제출을 focused 테스트로 확인한다. UI production 빌드 후 31(GFS2)·32(RBD)의 활성 webapp에 정적 자산만 배포한다. WEB-INF/META-INF·config·JAR·PID·별도 운영 파일을 보존하고 모든 자산 해시·활성 번들 식별자·HTTP 200을 확인한다.

배포한 UI에서 컴퓨트 직접 지정/연결, 디스크 사용자 지정/고정, Europa/기존 방식, 이미지 형식과 정책, QoS·공개 범위, 취소/실패·재시도 및 좁은 화면을 확인한다. 전용 오퍼링과 볼륨만 사용해 API·DB·실제 스토리지와 대조한 뒤 정리하며 운영 자원은 기준 목록과 비교한다. UI 빌드 결과와 Full Cloud CI를 구분한다.
