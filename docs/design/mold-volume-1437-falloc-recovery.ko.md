# #1437 GFS2 falloc 내용 불일치의 제한 재시도

## 결정과 범위

사용자 선택(2026-10-20): 호스트 커널·스토리지 수정은 범위에서 제외한다. 제품의 조치 범위는 검증된 Cloud 회피 경로이며, 구현·배포·기능 검증 완료로 #1437을 해결 종료한다. 커널·호스트·스토리지의 근본 수정은 제품 범위와 이 이슈의 종료 조건에서 제외한다. 회피 방식은 최초 시도 뒤 **새 이미지로 falloc을 최대 2회 재시도**한다. Full 전환은 하지 않는다.

이번 실측은 QEMU뿐 아니라 Python posix_fallocate, util-linux fallocate, truncate 후 posix_fallocate에서도 zero 불일치를 재현했다. 동일 실패 파일을 세 호스트에서 다시 열어 직접 읽어도 불일치가 유지됐다. sync, KEEP_SIZE 경로도 해결책으로 검증되지 않았다. 따라서 발생 계층은 Cloud/QEMU 상위에 한정되지 않으며, 커널 단독 결함인지 블록 장치·스토리지 경로 문제인지는 확정하지 않는다.

## 실행 상태와 불변 조건

1. 생성 의도·원본·용량·형식 검증 후 새 0700 임시 디렉터리에 falloc 이미지를 생성한다.
2. 기존 검증(독립 이미지, 정확한 크기·할당 블록, 전체 논리 데이터 및 zero tail)을 유지한다.
3. **qemu-img compare exit 1**인 내용 불일치에만 회피를 적용한다. 명령 실패/열기/읽기 오류(2 이상), I/O, 용량, 권한, 타임아웃은 재시도하지 않는다.
4. 첫 실패 이미지와 실제 zero 기준 파일을 풀당 단일 0700 진단 디렉터리에 보존한다. 공개 UUID 경로와 적용 receipt는 만들지 않는다.
5. 원본의 inode·크기·mtime 불변을 확인하고 이번 시도의 남은 파일을 정리한 뒤 새 임시 디렉터리에서 다음 시도를 시작한다. 같은 실패 inode를 고치거나 재사용하지 않는다.
6. 최초 포함 최대 3회, 동일 Context의 최초 제한 시간을 공유한다. 재시도마다 현재 가용 용량도 확인한다.
7. 성공한 시도만 receipt, fsync, 원자적 hard link 공개, 적용 증거를 반환한다. 요청/적용 정책과 메서드는 falloc 그대로다.
8. 모두 불일치하면 GFS2_ALLOCATION_CONTENT_MISMATCH를 반환한다. 잘못된 Ready·path·적용 증거를 만들지 않는다.

기존 공개 이미지의 응답 유실 재검증 경로는 재생성·교체하지 않는다. 동시 요청은 기존의 원자적 non-overwrite 공개 규칙을 유지한다. RBD와 기존 FT/DR 경로는 변경하지 않는다.

## 증거 보존 한도

- 경로: 풀 루트의 .cloudstack-allocation-failure-v1.
- 파일: 실패 image, 빈 생성일 때 실제 비교한 sparse zero 기준 파일, manifest.json.
- 풀당 첫 실패 1건. image 파일 길이 2 GiB 이하만 보존한다. 기준 파일은 sparse이다.
- 기존 슬롯(파일/디렉터리/symlink 포함)은 열거나 덮어쓰지 않는다. 한도 초과·슬롯 사용·캡처 실패를 로그/최종 오류에 명시한다.
- manifest는 요청 fingerprint·UUID·형식·정책·크기·시각·실제 비교 오류만 담으며 이미지의 바이트를 로그/API에 넣지 않는다.
- 슬롯은 자동 삭제하지 않는다. 운영자가 원인 분석을 위해 별도 보존한 뒤 명시적으로 정리한다. 슬롯을 만든 요청이 성공해도 첫 실패 증거는 남는다.
- 보존은 디스크의 추가 예약 보장이 아니다. 보존 이미지가 차지한 용량은 다음 시도의 실제 가용 용량 검사에 반영된다.

## 완료 범위와 제한

Cloud 보완의 완료 기준은 제한 재시도의 정확한 분류·전체 검증·원본/소유권/동시성·실패 증거 보존을 모듈 및 실제 GFS2에서 확인하고 31번 Agent에 배포하는 것이다. 간헐적 커널/호스트 경로의 실패 자체가 없어졌다고 주장하지 않는다. 3회 모두 실패하면 안전하게 생성 실패를 반환하는 동작도 완료된 제품 계약이다. #1434에서는 이 계약의 회귀를 확인하며, 외부 계층의 근본 수정을 제품 미완료 조건으로 남기지 않는다.
