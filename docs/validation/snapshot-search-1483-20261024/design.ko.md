# #1483 검색과 URL 상태 계약

Epic 브랜치 `dhslove/epic-1473-storage-snapshots`, 시작 HEAD `d1f3a3f6b10b`.

## 검색 계약

볼륨 UUID, MANUAL/RECURRING, HOURLY/DAILY/WEEKLY/MONTHLY, Zone, 계정/도메인/재귀, 프로젝트, 저장소, 이름/키워드, 태그를 기존 listSnapshots와 연결한다. intervaltype은 volumeid 유무와 무관하게 적용하고 RECURRING과 교집합을 취한다. MANUAL+주기 및 잘못된 enum은 API 431이다. 기본 스냅샷 유형 제외 규칙은 유지한다.

기본은 논리 스냅샷이고, 명시적인 스토리지 사본 모드만 locationtype을 받는다. 사본 행/건수/페이지는 copy.id 단위이며 위치와 저장소 열을 항상 표시한다. 사본 행은 읽기 전용이다. 전체 스냅샷 작업은 상세에서 수행한다. 논리 모드+위치, 서로 충돌하는 저장소, 계정+프로젝트, 미지원 state, 불완전하거나 중복 키인 태그를 URL/화면에서 설명하고 조회를 차단한다. API의 기존 showunique=true에서 locationtype 무시 계약은 유지한다. StorPool 복제 옵션은 추가하지 않는다.

## URL과 소유 범위

URL을 적용한 검색 상태의 기준으로 삼는다. 조건 적용·제거·초기화는 page=1이며 정렬/페이지 크기/현재 프로젝트를 유지한다. 뒤로 가기와 직접 링크는 해당 조건·페이지를 복원한다. 기본 보기는 UI URL 전용 projectid=0으로 명시하고 API에는 보내지 않는다. projectid=-1은 전체 프로젝트, 실제 UUID는 특정 프로젝트다. 공통 프로젝트 선택을 URL과 한 번만 동기화하고 해당 조건을 URL에서 지우지 않는다. 기본 보기 복귀는 전역 선택도 복원하고, 늦은 프로젝트 응답은 현재 경로/사용자/세션/프로젝트 조건과 일치할 때만 적용한다. 키워드 입력과 비우기는 다른 조건을 보존한다. 삭제된 원본 볼륨의 volumeid도 UUID로 보존한다. 현재 권한에서 지원하지 않는 저장소 필터는 무시하지 않고 차단한다.

볼륨 후보는 선택한 계정/도메인/재귀/프로젝트/Zone을 API에 전달한다. 서버 검색과 20건씩 추가 로딩을 사용하고 생성시각 동률은 volume.id DESC로 고정한다. 계정 후보는 listall=false로 요청해 서버의 강제 재귀를 피한다. 볼륨의 저장 경로 대신 이름을 표시하고 도메인만 계층 경로로 표시한다. 후보 페이지 변경·중복·권한 불일치·실패를 빈 결과와 구분하고 재시도를 제공한다. 계정/범위/검색어 변경, 대화상자 닫기, 권한 변경 이후의 오래된 응답은 적용하지 않는다. API 권한 검사를 유지한다.

## 대화상자

VM 공통 MoldDialog md(720px), 세로 폼, 2열/모바일 1열, 16px 행 간격, 20px 열 간격, 고정 공통 footer(초기화/취소/검색)를 사용한다. 오류와 후보 안내는 각 필드 아래 자연 높이를 차지한다. 테마 색상을 상속하고 고정 검정 글자를 사용하지 않는다. 상세 정보/선택 대상 요약을 중복 표시하지 않는다.

## 검증과 배포

31 GFS2와 32 RBD에 전용 도메인·계정·프로젝트·볼륨·실제 수동/주기 스냅샷을 만든다. snapshot_view의 독립 SQL oracle로 필터/ACL/중복 제거/건수/페이지 ID를 대조한다. 실제 브라우저에서 조작·URL 복귀·초기화·오류/재시도·늦은 응답·대화상자 가독성을 검증한다. 변경 Maven 모듈만 WSL ext4에서 빌드하고 관리 JAR 변경 class와 정적 UI만 배포한다. 서버 디렉터리/설정/기존 자원/보호된 FT 작업 트리를 보존한다. 전용 자원은 정상 API 삭제와 DB/스토리지 잔여 확인으로 정리한다. 전체 Cloud CI는 실행하지 않는다.
