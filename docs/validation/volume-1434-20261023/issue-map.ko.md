후속 승인 UI도 포함한다: [오퍼링 추가 폼](../offering-dialogs-20261023/report.ko.md). 컴퓨트/디스크 새 오퍼링을 실제 UI로 생성해 Europa 기본 RAW/off와 태그·기본 설명을 API에서 대조했다. 생성된 디스크 오퍼링으로 새 RBD 볼륨을 만들고 장치 번호를 비워 자동 연결·전체 zero까지 확인했다.

V01~V08은 위 대응과 최종 보고서의 실환경 지원/차단 표로 대조한다. 미지원 작업의 명확한 거절을 해당 작업의 지원 성공으로 세지 않는다. 활성 KVDO 엔진 검증, 독립 물리 장애 영역, 영구 공간 예약, 전체 Release CI는 완료 PASS에 추가하지 않는다.
