# #1432 볼륨·오퍼링 API/UI 결정표

대상 66 API. 각 행은 현재 UI 또는 의도적 미노출 결정이며 미결정 항목은 없다. 다른 이슈 소유 범위는 #1154/#1209/#1210에 유지한다.

권한 열은 실제 listApis 등록(A=Admin,D=DomainAdmin,U=User,P=User의 프로젝트 문맥)이며 객체 접근 허용을 뜻하지 않는다. 두 클러스터 일치 여부와 구체적인 UUID 거절·실행은 api-visibility.json 및 api-matrix.json을 참조한다. 프로젝트는 별도 역할이 아니라 API 호출의 소유 범위다.

각 API의 실제 요청 수와 오류 응답 수는 JSON에 별도 기록한다. 등록·소스 검토와 실제 성공을 혼동하지 않는다. 본 이슈는 전체 볼륨 수명주기/게스트 I/O 회귀의 완료를 주장하지 않으며 #1434로 연결한다.

- #1154: 컴퓨트 목록의 연결된 전용 디스크 오퍼링 링크로 대시보드 이동하는 문제. computeOnly 응답과 상세 연결 방식 안내는 선행 보완됐지만 목록 컬럼·링크 구분 및 최종 회귀는 이 이슈에서 마무리한다.
- #1209: VM 생성 메뉴에서 디스크 오퍼링이 10개를 초과할 때 선택기 페이지가 표시되지 않는 문제. 페이지/쪽수당 개수와 전체 후보 표시를 수정·검증한다.
- #1210: 데이터 볼륨 연결 대상 VM을 표시이름으로 찾도록 검색/표시를 개선한다. 표시이름 변경 후에도 내부 name을 추론하지 않고 선택해야 한다.

- #1434: 모든 기존 기능의 최종 통합 회귀, Running 게스트 워크로드, 장기 통계/암호화/Block 전용 환경은 본 이슈에서 미실증.
