# VM 상세 볼륨 작업 (#1110)

## 변경 사유와 범위
- VM 상세의 전체 폭 생성 버튼과 단순 조회 컴포넌트를 `VmVolumesTab`으로 교체한다. VM 스냅샷 탭처럼 생성/기존 연결/새로고침/검색 툴바와 행 작업을 제공한다.
- `CreateVolume`의 선택적 submitHandler는 기존 입력 검증/오퍼링/스토리지/KMS 폼을 재사용하기 위한 경계다. 이 경로에서는 소유자 선택을 숨기고 VM 계정·프로젝트·Zone을 고정한다. 다른 호출자는 기존 동작을 유지한다.
- `vmVolumeActions`는 생성→연결, 연결 해제→선택적 삭제를 단계별로 추적한다. 목록 행이 사라지거나 탭이 unmount되어도 동작은 유지한다. 완료된 단계는 재실행하지 않는다.
- 실패가 확인된 단계만 재시도하거나 후속 작업을 취소할 수 있다. 생성/연결 해제가 성공한 볼륨을 실패 보상으로 자동 삭제하지 않는다. 응답 유실은 실패와 구분한다. job ID가 있으면 같은 job 결과만 재조회하고, ID까지 유실되면 자동 재전송하지 않는다.
- 공통 pollJob의 기존 bounded polling/알림을 재사용한다. 계정·프로젝트·세션 변경 시 operation registry를 비워 후속 mutation을 중단한다. 삭제 직전에 VM, 볼륨 attachment, API 권한을 다시 확인한다.
- ROOT는 삭제하지 않는다. ROOT 연결 해제는 Stopped 및 서버가 지원하는 하이퍼바이저에서 비관리형 스토리지를 조회하여 확인한 경우만 허용한다. 일반 계정의 스토리지 조회 권한이 없으면 보수적으로 차단한다.
- 공유/다중 연결 및 flatten 진행 볼륨은 차단한다. hot-unplug, 오퍼링, 장치 수, backup/snapshot 등 최종 동시성·스토리지 정책은 기존 서버 검증을 유지한다.
- 공용 VolumesTab에서도 같은 VM refresh 전 배열을 지우는 코드를 제거한다. 컬럼을 첫 행의 속성 대신 안정적인 schema/API capability로 결정하여 다른 사용처의 깜빡임도 방지한다.
- 새 VM 볼륨 탭은 10초 자동 갱신과 최신 request token을 유지한다. 초기 조회에만 loading을 표시하고, 갱신 실패 시 이전 행을 보존한다. 같은 VM 객체의 교체는 폼/선택/검색을 초기화하지 않는다. 응답 데이터가 같으면 행 배열도 교체하지 않는다.

## 안전 경계
- 기본 선택: 연결 해제 후 보존.
- 일반 삭제: destroyVolume(expunge=false). 서버 정책에 따른 이후 영구삭제 가능성을 안내한다.
- 영구삭제: 권한/feature가 허용하는 경우 destroyVolume(expunge=true). 같은 확인창에서 복구 불가와 위험 버튼을 표시한다.
- API 결과를 잃은 요청은 무조건 재시도하지 않는다. 브라우저 전체 새로고침 후에는 공통 작업 기록/전역 볼륨 목록으로 서버 결과를 확인해야 한다. 페이지 재시작을 넘어 자동으로 삭제를 재개하는 영속 큐는 만들지 않는다.
- 별도 서버 모듈이나 DB 변경은 없다. Docker UI 모듈만 빌드/배포한다.

## 추가 요청 반영
- 생성 후 연결/기존 연결 모두 선택적인 Device ID를 받는다. 비워두면 자동 배정하며 생성 API에서는 제거하고 attachVolume에만 전달한다. 0(ROOT), 3(예약), 음수/소수 및 사용 중인 번호를 거부한다. 제출 직전에 현재 VM 볼륨 목록을 재조회해 번호 충돌도 재검증한다. 하이퍼바이저별 최대 번호와 게스트 장치명 매핑은 서버 정책을 유지한다.
- 목록에 볼륨 번호 컬럼을 표시해 연결 결과를 확인할 수 있다.
- 결과 대화상자 버튼은 우측 정렬 및 8px 간격을 사용한다.
- 행의 디스크 분리 버튼과 드롭다운 버튼은 inline-flex/align-items:center, 동일 높이 24px 및 8px 간격으로 배치한다. 링크형 버튼의 서로 다른 수직 패딩을 제거한다.

## 연결 안내 문구의 테마 및 간격
- 생성 및 기존 볼륨 연결의 Device ID 도움말에 테마 보조 글자색을 지정한다. 기본 검정색이 다크 배경에서 읽히지 않는 문제를 방지한다.
- 입력 상자 아래 도움말에 8px 여백을 둔다. 검증 오류는 테마 오류 색상을 별도로 유지한다.
